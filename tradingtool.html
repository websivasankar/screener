Methodology
How the System Works
NSE EOD Data Collection
Daily bhav copy, FO participant OI (fao_participant_oi), FII cash stats, and VIX history downloaded from NSE archives.
Quant Feature Extraction
Breadth, delivery spikes, momentum MA, high/low resilience, sector rotation, and options OI structure computed per symbol.
Python Labels All Rules
Regime (BULL/BEAR/NEUTRAL/TRANSITION), VIX zone, conviction cap, FII vs Client divergence, breadth trend, and stock futures sentiment are all computed in Python — zero hallucination risk.
Claude Finds Anomalies
Claude receives raw numbers only — no labels, no rules. It identifies unusual patterns, writes the OI / FII / breadth / F&O narratives, synthesis, and action plan in a single API call.
Static Site Publish
All HTML reports and screeners are copied to GitHub Pages and served from infoalpha.in — no server, no login, no tracking.
